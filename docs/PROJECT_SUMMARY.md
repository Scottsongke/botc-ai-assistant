## 🎓 关键技术实现

### 贝叶斯推理

```javascript
// 先验概率
P(角色) = 配置数量 / 总玩家数

// 更新公式
P(角色|证据) ∝ P(证据|角色) × P(角色)

// 归一化
P(角色) = P(角色) / Σ所有角色概率
```

### 矛盾检测

```javascript
// 同一角色检测
if (跳同一角色的玩家 > 1) {
  至少 (玩家数 - 1) 人在说谎
}

// 信息矛盾检测
if (信息A.内容 ≠ 信息B.内容 && 关于同一对象) {
  至少一方: 说谎 OR 被醉酒 OR 被下毒
}
```

### 策略决策树

```
我的角色 → 游戏阶段 → 场上局势 → 具体建议
    ↓
占卜师 → 第2天 → 有可疑玩家 → 今晚验证
    ↓
猎手 → 终局 → 恶魔概率>80% → 建议开枪
```
